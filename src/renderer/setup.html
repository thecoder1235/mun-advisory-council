Set up MUN Advisory Council

The app needs an API key to run its advisory agents. This is a one-time step.

  1. Create a free NVIDIA account. Go to build.nvidia.com and sign up. It asks for phone verification. This is free and gives you enough credits for many sessions.
  2. Open the page for this exact model: deepseek-ai/deepseek-v4-pro-0813 Search for it on the site. You need to be on that model's own page for the next step to work.
  3. Click "Get API Key" on that model's page. It has to be the button on the model page. A key made from your account or profile section will not work — NVIDIA issues keys per model, and a key from anywhere else simply cannot call this one. This is the single most common way to lose an hour here.
  4. Paste the key below. It starts with nvapi-.
  5. Enter the model name when asked, exactly as: deepseek-ai/deepseek-v4-pro-0813

Your key works.



    

    

  


  

    
How to use this

    

      
Add your own character first, then everyone else at the table.

      
The council reasons only from the wiki pages you load. Nobody loaded means nothing to reason from.


      
A full council takes 3–9 minutes.

      
The model has to start a GPU on every question — that alone is about two minutes, every time, even for a
          question you just asked. This is NVIDIA's provisioning, not the app being slow.


      
Cards appear as each agent finishes.

      
You do not have to wait for all of them. Read the first card while the rest are still working.


      
UNVERIFIED means it is not in the source.

      
The model inferred it. It will not survive a challenge in committee — do not build an argument on it.


      
COMICS and FILM are separate continuities.

      
They frequently contradict each other, and where they do is often the most useful thing on screen: it tells
          you exactly which claims an opponent can contest.


      
The highest-value question is "here is my plan, where does it break?"

      
The council is built to attack a plan, not to praise one. Give it something to attack.
